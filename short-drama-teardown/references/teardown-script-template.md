## 三、集间衔接与人工听打补录（兜底通道 C3）

每集末尾必填：
```text
→ 下集钩子（末句台词 + 卡点画面）：____
→ 承接上集：____
```

ASR 不可用（无音轨 / 方言过重 / 无字幕轨）时，本节兼作人工听打补录区：边听边填上表「句号/时间码/台词/说话人/画面核验」五列，时间码取整到 0.5s，其余规程与通道 B 三把铁锁完全一致。

## 四、向下游交接（写 HTML 报告前必读）

逐字稿定稿后，按 `references/data-schema.json` 的字段把内容填进 JSON（`transcript` 数组里的一句 = 本表一行），再跑 `python scripts/export_html.py data.json --out 报告.html`。
