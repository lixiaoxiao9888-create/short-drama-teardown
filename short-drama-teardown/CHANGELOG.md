# CHANGELOG

## V4.0.1 补丁 2（2026-11-16）· 视觉能力门禁（不升版）

**背景**：三把铁锁的第一把（同人归并）与第三把（逐句三看）本质是「真看图」。实测发现：纯文本模型调 `read` 读图会被运行时丢弃（返回「Current model does not support images」），而流程照跑不误——等于在**没看到画面的情况下**批量填 `张嘴对白 / 闭嘴OS`，等于造假稿。

**修复**：SKILL.md 新增「0 号前置闸：视觉能力门禁」——开工前先 `read` 一张帧自检；不支持图像时禁止靠语义推测说话人与 OS/VO，必须①切支持 `text+image` 的模型，或②转人工看图填列，两者都不通就停，不许出半截稿；并补「读图节奏（一次 8~12 张，头部全量集才逐句读图）」、「人物卡视觉锚点必须来自实际读过的帧」。

## V4.0.1 补丁（2026-11-16）· BOM 兼容修复（不升版）

**问题**：`export_html.py` 用 `encoding="utf-8"` 读 data.json，遇到 UTF-8 BOM 直接抛 `Unexpected UTF-8 BOM` 并以退出码 2 中止；`srt_to_script.py` / `batch_prep.py` 读字幕同理，BOM 会粘在首行，导致首条时间轴判不出数字、首句丢失。Windows 记事本、PowerShell `Set-Content` / `>` 写出的文本默认带 BOM，实测必撞。

**修复**：
1. 新增 BOM 安全读入口：`srt_to_script.read_text()` / `srt_to_script.load_json_file()`、`export_html.load_json_file()`；编码统一用 `utf-8-sig`（对无 BOM 文件同样正确）。
2. 三处读点全部改走上述入口：`srt_to_script.py` 主流程读字幕、`export_html.py` 读 data.json、`batch_prep.py` 读字幕（`utf-8-sig`）。
3. 三个 `--selftest` 各加一条回归断言：临时写出带 BOM 的 SRT / JSON，必须照常解析、首句不丢。

**验证**：三脚本 `--selftest` 全 PASSED；CLI 实测 BOM SRT → 2 句完整、纠偏与 BOM 清零；BOM data.json → 正常出 18,458 字节 HTML；无 BOM 反向回归同样通过。

## V4.0.1（2026-11-16）· V4.0 修复版

**结论先说**：V4.0 的扒稿链路可用，但交付层有两个 P0（JSON 无字段契约、抽帧失败静默）会让第一次真用就拿到空白报告或缺帧的「1:1 绑定表」。本版只修不改设计：四段式交付、三把铁锁、进场双通道门禁一条未动。

### P0 阻断级（会直接毁掉交付物）

1. **补 `references/data-schema.json`（JSON 字段契约）**
   - 问题：三份模板全是 markdown 表，SKILL.md 只说「汇总为结构化 JSON」，而 `export_html.py` 要的字段只存在于脚本 selftest 里；字段对不上时脚本不报错，直接渲染出四块空白。
   - 修复：新增 schema 文件（meta / characters / transcript / script_scenes / skeleton 五块逐字段说明）；`export_html.py` 新增 `--write-example` 一键吐标准样例 JSON；`build` 前跑 `validate_data()` 字段体检——结构性为空直接拒绝出稿（退出码 4），字段缺项逐条打印 `⚠️ 字段体检`。

2. **抽帧失败不再静默**
   - 问题：`grab_single_frame()` 返回值被丢弃。实测一句落在片长外的台词：图没生成，脚本照样打印「已完成 N 句」，索引表仍列文件名。
   - 修复：逐帧校验 ffmpeg 返回码 + 文件是否落盘且非空；失败句在索引表标 `❌ 未抽到帧`，结尾汇总失败句号并以退出码 3 报警；`--grab-frame` / `--crop-sub` 同样加失败退出码。

### P1 功能级

3. **`--merge N` 换人/新块判定真正落地**：旧版注释写「无换人特征才拼接」但代码只看了间隔与句末标点，实测把「你个 / 老狐狸 / 付寒周心想…」三句吞成一句。新版三重校验：续句标点或 ≤12 字碎片、不以换人特征词开头、不含 OS/系统/旁白特征块，且单次合并链上限 2 句；被并句在逐字稿备注打 `⤵` 留痕，摘要新增「碎句合并 N 处」。
4. **`fmt()` 毫秒进位修复**：旧版 `round((t-int(t))*1000)` 在 .9996 上溢出被 `%1000` 归零，`59.9996` 渲染成 `00:59.000`（差 1 秒，且剪映微秒除 1e6 高频命中）。改为先整体转毫秒再拆分。
5. **OS 统计口径修复**：旧版 `'OS' in clue` 把兜底串「待核（对白/OS）」也算成画外音，实测 6 句全报画外音（真实 3 处）。改为只认 `〔〕` 包裹的判定标签；摘要新增碎句合并计数。
6. **打印/PDF 黑底黑字修复**：旧 print 样式只改 body 背景与字色，没重置 `--surface-2`，`△` 动作行是深底 + 继承 #000。新版 print 块强制整套浅色变量并逐class覆盖。

### P2 一致性与发布纪律

7. **版本串统一 V4.0.1**：旧包四套并存（SKILL.md 4.0.0 / export_html V4.0 / batch_prep V3.1 / srt_to_script V3.0，模板 ★权威 V3.1/V3.0）。现全部对齐。
8. **术语悬挂清理**：模板「T4 人工听打模板」→「人工听打补录（兜底通道 C3）」，并在 SKILL.md 能力边界写明兜底规程；稿头新增「逐句抽帧核验 __/__」字段。
9. **补回「本集性质」三档定义**：SKILL.md 新增第五节（头部全量 / 中段抽样 / 尾部结局集 + 「结论只认头部全量」），此前模板要填该字段但定义被删。
10. **补回工具链自检**：SKILL.md 第三节点名 python/ffmpeg 版本检查与三条 `--selftest`，避免跑到一半才发现没 ffmpeg。
11. **能力边界显式声明**：SKILL.md 〇节新增「本包不承接只给剧名的检索找剧」，防止模型照 description 硬接。
12. **新增 `README.md` / `CHANGELOG.md` / `CHECKLIST.md`**，压缩包不再是 7 个裸文件，改动可追溯。
13. **HTML 默认浅色主题**（`--theme light|dark`，默认 light），复制按钮加 `execCommand` 降级与失败提示；三处 `io.open().write()` 改为 `with` 上下文。
